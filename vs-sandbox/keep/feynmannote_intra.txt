--use-fabric
No, this is NOT at the InfiniBand level. It's purely a CUDA GPU memory API choice:

Without --use-fabric (default):
    cudaMalloc(ptr, size);  // Traditional CUDA memory allocation
    cudaIpcGetMemHandle();  // Traditional IPC for GPU-to-GPU sharing

With --use-fabric:
    cuMemCreate();          // Modern CUDA memory management
    cuMemMap();             // Virtual memory mapping
    CU_MEM_HANDLE_TYPE_FABRIC;  // Fabric handle for sharing

What "Fabric" means here:
    CUDA Fabric = NVIDIA's modern memory virtualization/sharing API
    Introduced with newer CUDA versions for more flexible memory management
    Better suited for complex multi-GPU/multi-node memory sharing patterns
    Has nothing to do with network fabric or InfiniBand - it's purely GPU memory-level
